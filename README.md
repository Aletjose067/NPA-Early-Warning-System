# NPA Early Warning System

A Machine Learning based banking analytics project that predicts the risk of loan accounts becoming Non-Performing Assets (NPA).

## Features

- NPA Risk Prediction
- Random Forest Model
- XGBoost Model
- Flask Web Application
- Email Alert System
- Risk Probability Dashboard

## Tech Stack

- Python
- Pandas
- Scikit-Learn
- XGBoost
- Flask
- Bootstrap

## Project Workflow

Customer Data → Risk Prediction → Risk Classification → Email Alert
